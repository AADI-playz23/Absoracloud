# AbsoraCloud Managed Game Cloud Node (HF Gradio Space)

This Hugging Face Space runs the AbsoraCloud Managed Minecraft Cloud Server engine (2 vCPU / 16GB RAM) using the Python **Gradio SDK** (`sdk: gradio`).

## Environment Variables required in HF Space Settings:
- `RENDER_SERVER_URL`: `https://absoracloud.onrender.com`
- `WORKER_TOKEN`: `hf_space_mc_token_secure_77`
- `TARGET_USER_ID`: `usr_demo_mc`
- `SPACE_ID`: `YOUR_USERNAME/absoracloud-game-node`
